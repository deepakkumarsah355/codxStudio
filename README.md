# CodX Studio Website

A responsive, dark futuristic landing page inspired by the CodX Studio reference design.

## Structure

- `index.html` — main page
- `css/style.css` — complete responsive styling and visual effects
- `js/main.js` — navigation, active sections and newsletter interaction
- `assets/` — reserved for future logos/icons/images

## Run

Open `index.html` directly in a browser, or use IntelliJ/VS Code Live Server.

No build step is required.
